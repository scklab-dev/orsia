# Notebook support

This package holds example-specific input preparation, presentation, local archival and reference comparison for the two canonical notebooks. Reusable instrument and radiative calculations remain in the public Orsia libraries; the notebooks select scientific inputs, optical laws and scan layouts explicitly.

`five_band_scenario.py` loads the five-band JSON settings and verified acquisition manifest into a notebook-local `FiveBandScenario` Pydantic V2 model. The helper resolves named paths and the UTC datetime and preserves the manifest's original checksum/provenance contract. The model contains inputs and settings; the notebook contains the public scientific calls. Pydantic is a development dependency. `five_band_gases.py` prepares the example's trace-gas profiles and retains compatibility adapters to the public Data/Radiative measured-spectrum APIs. `prepare_spectroscopy.py` explicitly imports the retained spectroscopy into a new offline collection. The five-band notebook reads that collection once, selects named references and evaluates each contribution with explicit physics and retained temperature diagnostics. `notebook_five_band_support.py` handles local verification, reference-array adaptation, timing and plots. Each case keeps species selection, public absorption/optics calls and its solar or thermal solver call in its own section. `notebook_sasktran2_cache.py` manages the reference cache and starts `notebook_sasktran2_layers.py` as a process-isolated worker using its explicit file path and the notebook's `sys.executable`. SASKTRAN2 is installed with the default development dependencies in the same workspace `.venv`.

The instrument-response notebook contains six explicit end-to-end detector-owned chains. `notebook_frame_display.py` presents source images, native electrons/DN, products, coverage, achieved responses and inverse diagnostics, and extracts source-only inspection text. `instrument_notebook_checks.py` supplies independent bounded quadrature, fixed-strip and slit-guard checks through public forward APIs. `notebook_instrument_support.py` retains shared display/runtime settings and historical separable-reference presentation. `notebook_ground_pixel.py` remains an independent reference fixture, including its separate common-exposure-noise experiment; the principal notebook uses public calibration/reconstruction APIs directly. `notebook_instrument_responses.py` extracts current figures into the chain-specific output directory.

`prepare_five_band.py` acquires the baseline demonstration inputs; `prepare_five_band_enriched.py` verifies retained enriched inputs or acquires them with explicit `--download`. `replay_instrument_response.py` runs the current instrument cells on the retained spectral scene and compares archived numerical products. The root `justfile` invokes these modules with `python -m notebooks.support.<module>`. The [notebook guide](../README.md) describes their recipes and scientific scope.
